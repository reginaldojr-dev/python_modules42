Hello Garden

Turn-in directoryex0/
Files to submitft_hello_garden.py
Authorizedprint()

Você começa com uma função que apenas mostra uma mensagem. Nada de programa principal ainda.

programa Python - conceito

Um programa Python é um arquivo de texto com extensão .py. O interpretador lê esse arquivo de cima para baixo e executa as instruções conforme encontra cada linha.

Como usar agora: no Módulo 00 você não está montando um programa completo; está criando arquivos que serão importados/testados por outro arquivo. Por isso, qualquer código solto fora da função pode rodar na hora errada.

Erro comum: escrever testes no final do arquivo do exercício. Se quiser testar, use o arquivo auxiliar indicado pelo projeto ou remova chamadas extras antes de entregar.

função - conceito

Uma função é um bloco de código com nome. Ela serve para guardar uma ação reutilizável. A linha def nome(): cria a função; o bloco indentado abaixo dela é o corpo.

Como usar agora: escreva exatamente a função pedida pelo subject. O corpo dela deve fazer o trabalho. Não precisa criar main nem chamar a função dentro do mesmo arquivo.

def avisar():
    print("Aviso pronto")

# Nada apareceu ainda. A função só foi definida.
# O corpo só roda quando alguém chamar avisar().

Erro comum: confundir definir com executar. Se você só escreveu def, a função existe, mas ainda não produziu saída.

print() - conceito

print() envia texto para a saída padrão, normalmente o terminal. Ele é usado quando o exercício espera que a própria função mostre algo.

Como usar agora: coloque dentro do print() exatamente o texto que deve aparecer. A função print() já adiciona uma quebra de linha no final por padrão.

print("Relatório pronto")
print("Total:", 3)

Erro comum: usar return quando o subject pede para exibir. return devolve valor para quem chamou; print() mostra no terminal.

tipo - conceito

Todo valor em Python tem um tipo. O tipo decide o que uma operação significa. "5" + "3" junta textos e vira "53"; 5 + 3 soma números e vira 8.

Como usar agora: quando o dado vai participar de cálculo, ele precisa ser número, não texto.

int() - conceito

int() converte um valor para inteiro quando isso é possível. É a ponte entre a entrada textual do usuário e operações matemáticas.

Como usar agora: leia com input(), converta com int(), guarde em uma variável numérica e só então calcule.

largura_texto = input("Largura: ")
largura = int(largura_texto)
print(largura * 2)

Erro comum: fazer conta com o retorno cru de input(). Ele ainda é string.

operadores aritméticos - conceito

Operadores aritméticos criam expressões numéricas: + soma, - subtrai, * multiplica, / divide.

Como usar agora: monte uma expressão com os valores convertidos. Se precisar guardar o resultado para imprimir depois, use outra variável.

base = 8
altura = 4
area = base * altura
print("Área:", area)

booleano - conceito

Um booleano é um valor lógico: True ou False. Comparações como >, <, == e != produzem booleanos.

Como usar agora: transforme a frase do subject em uma pergunta de verdadeiro/falso. Ex.: “é maior que 60?” vira valor > 60.

tem_estoque = quantidade > 0
print(tem_estoque)

if/else - conceito

if escolhe um caminho quando a condição é verdadeira. else escolhe o caminho alternativo quando ela é falsa.

Como usar agora: coloque a mensagem do caso verdadeiro dentro do bloco do if e a outra mensagem dentro do else. A indentação faz parte da sintaxe.

if quantidade > 0:
    print("Há peças no estoque")
else:
    print("Estoque vazio")

Erro comum: errar fronteira. “Mais de 60” é > 60, não >= 60.

Count to Harvest

Novo passo: repetir uma ação várias vezes, primeiro com laço e depois com recursão.

for/range() - conceito

range() representa uma sequência de inteiros. O for percorre essa sequência, repetindo o bloco uma vez para cada valor.

Como usar agora: se precisa contar de 1 até n, lembre que o fim do range não é incluído. Por isso, geralmente você usa range(1, n + 1).

for dia in range(1, 4):
    print("Dia", dia)

# Saída: Dia 1, Dia 2, Dia 3

Erro comum: usar range(1, n) e parar um número antes do necessário.

recursão - conceito

Recursão acontece quando uma função chama a si mesma para resolver uma versão menor do mesmo problema. Ela precisa de um caso base, que é a condição que para as chamadas.

Como usar agora: identifique o contador atual e o limite. A cada chamada, aproxime o contador do limite. Quando chegar no limite, pare.

def contar_ate_3(atual):
    if atual > 3:
        return
    print(atual)
    contar_ate_3(atual + 1)

Erro comum: esquecer de mudar o valor na chamada recursiva; aí a condição de parada nunca chega.

Faça a versão iterativa antes da recursiva.Próximo: M00 Ex07

type hints - conceito

Type hints são anotações que dizem quais tipos uma função espera receber e qual tipo ela devolve. Elas servem como documentação e como base para ferramentas de checagem, como mypy.

Como usar agora: escreva os tipos na assinatura exatamente como o subject pede. -> None indica que a função não devolve valor útil; ela só imprime.

def registrar(nome: str, quantidade: int) -> None:
    print(nome, quantidade)

Erro comum: achar que type hint converte valor. quantidade: int não transforma string em int automaticamente.

método de string - conceito de apoio

Strings são objetos. Métodos de string são ações prontas que você chama com ponto, como .capitalize(), .lower() ou .strip().

Como usar agora: quando o subject pedir uma forma específica de escrita, procure um método de string que produza essa transformação sem alterar o texto original manualmente.

peca = "pedal"
print(peca.capitalize())  # Pedal

Erro comum: esquecer que strings são imutáveis. O método devolve uma nova string; ele não altera a original.

__name__ - conceito

Todo arquivo Python carregado pelo interpretador é um módulo, e todo módulo recebe uma variável especial chamada __name__. Se o arquivo foi executado diretamente, __name__ vale "__main__". Se foi importado por outro arquivo, vale o nome do módulo.

Como usar agora: use isso para diferenciar “estou rodando este arquivo como programa” de “alguém importou minhas definições”.

print(__name__)

# Rodando direto: __main__
# Importado: nome_do_arquivo

if __name__ == "__main__" - conceito

Esse bloco cria um ponto de entrada. O código dentro dele só roda quando o arquivo é executado diretamente, não quando é importado.

Como usar agora: coloque dentro desse bloco as linhas que montam e exibem o programa deste exercício. Definições reutilizáveis, como classes e funções, podem ficar fora.

def mostrar():
    print("Executando")

if __name__ == "__main__":
    mostrar()

Erro comum: no Módulo 00 isso era proibido; aqui passa a fazer sentido porque o subject pede um programa executável.

shebang - conceito de apoio

Shebang é uma primeira linha como #!/usr/bin/env python3. Em sistemas Unix, ela indica qual interpretador deve rodar o arquivo quando ele é executado como comando.

Como usar agora: entenda para explicar na defesa. Mesmo que você rode com python3 arquivo.py, o avaliador pode perguntar para que serve essa linha.

#!/usr/bin/env python3

Garden Data Organizer

Turn-in directoryex1/
Files to submitft_garden_data.py
Authorizedprint()

Aqui nasce OOP: o subject pede uma classe para modelar várias entidades semelhantes.

classe/objeto - conceito

Uma classe é um molde que descreve um tipo de coisa. Um objeto, também chamado de instância, é uma coisa concreta criada a partir desse molde. A classe diz “todo objeto desse tipo pode ter estes dados e estes comportamentos”.

Como usar agora: quando o subject diz que várias entidades têm os mesmos campos, pare de criar variáveis soltas e crie uma classe. Depois, crie uma instância para cada entidade real.

class Ferramenta:
    pass

martelo = Ferramenta()
chave = Ferramenta()

# martelo e chave são objetos diferentes
# criados a partir do mesmo molde.

Erro comum: achar que a classe é “uma planta específica”. A classe é o modelo; cada objeto é uma planta/ferramenta/registro específico.

atributo - conceito

Atributo é um dado guardado em um objeto. Cada instância pode ter seus próprios valores para os mesmos atributos. Isso permite ter vários objetos parecidos sem misturar os dados de um com os dados do outro.

Como usar agora: identifique os dados que toda entidade do subject possui. Esses dados viram atributos.

martelo.nome = "Martelo"
martelo.peso = 2

chave.nome = "Chave inglesa"
chave.peso = 1

Erro comum: usar variáveis globais para dados que pertencem a um objeto. Se o dado descreve uma instância, ele deve morar nela.

self - conceito

self é a referência ao próprio objeto dentro de um método. É assim que o método sabe qual instância deve ler ou alterar. O nome self é convenção forte em Python.

Como usar agora: coloque self como primeiro parâmetro dos métodos de instância. Use self.atributo para acessar dados daquele objeto.

class Ferramenta:
    def mostrar(self):
        print(self.nome)

martelo = Ferramenta()
martelo.nome = "Martelo"
martelo.mostrar()

Erro comum: esquecer self no método. Ao chamar martelo.mostrar(), Python passa martelo automaticamente como primeiro argumento.

método - conceito

Método é uma função definida dentro de uma classe. Ele representa um comportamento daquele tipo de objeto. Um método pode apenas consultar dados, exibir algo ou alterar o estado do objeto.

Como usar agora: transforme ações que pertencem à entidade em métodos. Se a ação usa dados do objeto, ela provavelmente deve receber self.

class Ferramenta:
    def mostrar(self):
        print(f"{self.nome}: {self.peso}kg")

Erro comum: criar função solta quando o subject pede que a entidade tenha comportamento próprio.

Novo passo: a classe criada antes ganha métodos que mudam o próprio objeto ao longo do tempo.

estado do objeto - conceito

Estado é o conjunto de valores atuais dos atributos de um objeto. Se um objeto tem altura = 25 e depois passa para altura = 26, o estado mudou.

Como usar agora: antes de escrever os métodos, desenhe o estado inicial e como ele deve ficar após cada dia/chamada. Isso evita métodos que imprimem bonito mas não atualizam nada.

# estado inicial
sensor.temperatura = 20

# depois de calibrar
sensor.temperatura = 21

método mutador - conceito

Um método mutador altera atributos do próprio objeto. Ele é diferente de um método que apenas exibe ou calcula algo temporário.

Como usar agora: se a ação deve mudar altura, idade, contador ou qualquer atributo persistente da instância, use self.atributo = novo_valor dentro do método.

class Contador:
    def aumentar(self):
        self.valor = self.valor + 1

Erro comum: calcular um novo valor em variável local e nunca guardar em self. Quando o método termina, a mudança desaparece.

round() - conceito de apoio

round(valor, casas) arredonda um número. Com uma casa decimal, round(3.1415, 1) vira 3.1.

Como usar agora: use quando o subject pede saída arredondada. Pense se quer guardar o valor arredondado no objeto ou só arredondar na hora de mostrar.

medida = 12.678
print(round(medida, 1))  # 12.7

Turn-in directoryex4/

Novo passo: proteger dados para que valores inválidos não corrompam o objeto.

encapsulamento - conceito

Encapsular é proteger o estado interno do objeto, controlando como ele é lido e alterado. A ideia não é esconder por esconder; é impedir estados inválidos.

Como usar agora: defina quais regras sempre devem ser verdadeiras. Depois faça qualquer alteração passar por métodos que validam essas regras.

# Regra de exemplo:
# estoque nunca pode ser negativo

atributo protegido - conceito

Em Python, um atributo começando com um underscore, como _peso, sinaliza “uso interno”. É uma convenção entre programadores: não acesse diretamente de fora da classe.

Como usar agora: guarde os valores internos como self._valor e ofereça métodos para ler/alterar. O subject pede convenção protegida, não __valor com name mangling.

class Caixa:
    def __init__(self, peso):
        self._peso = peso

Erro comum: achar que underscore bloqueia acesso. Ele não bloqueia tecnicamente; ele comunica intenção.

getter/setter - conceito

Getter é método de leitura controlada. Setter é método de escrita controlada. O setter valida antes de aceitar uma mudança.

Como usar agora: use get_... para devolver o valor e set_... para validar e atualizar. Se o valor for inválido, imprima a mensagem pedida e mantenha o objeto consistente.

class Caixa:
    def set_peso(self, peso):
        if peso < 0:
            print("Peso inválido")
            return
        self._peso = peso

    def get_peso(self):
        return self._peso

Exercise 05

Specialized Plant Types

Turn-in directoryex5/
Files to submitft_plant_types.py
Authorizedsuper(), print(), range(), round()

Novo passo: criar tipos especializados que reaproveitam o comportamento comum da classe base.

herança - conceito

Herança cria uma relação “é um”. Uma subclasse é um tipo especializado da classe base. Ela reaproveita atributos/métodos comuns e adiciona o que é específico.

Como usar agora: coloque na classe base o que todas as especializações têm em comum. Nas subclasses, coloque só os dados e comportamentos exclusivos.

class Veiculo:
    def __init__(self, nome):
        self.nome = nome

class Bicicleta(Veiculo):
    pass

bike = Bicicleta("urbana")

Erro comum: usar herança para “tem um”. Se A tem B, isso é composição; se A é um tipo de B, isso é herança.

super() - conceito

super() dá acesso ao método da classe base a partir da subclasse. É muito usado para reaproveitar o __init__ ou parte de um método sobrescrito.

Como usar agora: no __init__ da subclasse, chame super().__init__(...) com os dados comuns. Depois defina os atributos específicos da subclasse.

class Veiculo:
    def __init__(self, nome):
        self.nome = nome

class Bicicleta(Veiculo):
    def __init__(self, nome, marchas):
        super().__init__(nome)
        self.marchas = marchas

Erro comum: esquecer super().__init__(). Os atributos comuns da classe base não serão criados.

sobrescrita - conceito

Sobrescrever é redefinir na subclasse um método que já existe na classe base. A chamada usa a versão da subclasse, permitindo especialização.

Como usar agora: se a saída da classe especializada precisa mostrar os dados comuns e também os extras, chame o método da base com super() e acrescente a parte específica.

class Veiculo:
    def mostrar(self):
        print(self.nome)

class Bicicleta(Veiculo):
    def mostrar(self):
        super().mostrar()
        print("Marchas:", self.marchas)

polimorfismo - conceito de apoio

Polimorfismo permite chamar o mesmo método em objetos de tipos diferentes, confiando que cada objeto sabe responder do seu jeito.

Como usar agora: mantenha métodos com o mesmo nome e o mesmo papel geral nas subclasses. Assim uma função externa pode chamar objeto.show() sem verificar o tipo exato.

for item in itens:
    item.mostrar()  # cada classe decide como se mostrar

Novo passo: adicionar comportamentos ligados à classe, não só à instância, e um componente interno de estatísticas.

@staticmethod - conceito

Método estático é uma função colocada dentro da classe por organização, mas que não precisa acessar nem uma instância (self) nem a própria classe (cls).

Como usar agora: use para uma pergunta utilitária ligada ao domínio. Se a lógica só depende dos parâmetros recebidos, ela é boa candidata a estática.

class Medidor:
    @staticmethod
    def passou_do_limite(valor):
        return valor > 100

@classmethod - conceito

Método de classe recebe cls, que representa a classe usada na chamada. Isso permite criar objetos sem fixar o nome da classe diretamente.

Como usar agora: use como construtor alternativo quando existe uma forma especial de criar uma instância.

class Caixa:
    @classmethod
    def vazia(cls):
        return cls("sem etiqueta", 0)
